# 🧠 Online Quiz Application

A modern and interactive **Online Quiz Application** built using HTML, CSS, JavaScript, and Bootstrap 5. Test your JavaScript knowledge with multiple-choice questions in a premium, responsive interface.

## ✨ Features

- 🎯 **10 JavaScript Questions** – Practice JavaScript concepts with multiple-choice questions.
- ⏱️ **Countdown Timer** – Each question has a 30-second timer.
- ✅ **Instant Answer Selection** – Select an answer and receive visual feedback.
- 📊 **Score Calculation** – Automatically calculates your final score.
- 📝 **Answer Review** – Review your selected answers alongside the correct answers.
- 🔄 **Restart Quiz** – Restart the quiz and try again.
- 🎨 **Premium UI** – Modern dark-blue theme with gradient backgrounds, glassmorphism, and hover effects.
- 📱 **Responsive Design** – Designed to work across desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

- 🌐 HTML5 – Application structure
- 🎨 CSS3 – Styling, gradients, animations, and responsive design
- ⚡ JavaScript – Quiz logic, timer, answer selection, and scoring
- 🅱️ Bootstrap 5.3.8 – Layout and responsive components
- 🔤 Google Fonts – Inter typography

## 📚 Topics Covered

The quiz includes JavaScript concepts such as:

- Type coercion
- `typeof` operator
- `NaN` and `null`
- Floating-point precision
- Array methods like `map()` and `filter()`
- Equality operators (`==` and `===`)
- Boolean conversion
- String and number operations

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in your browser, or run it using the Live Server extension.
5. Start answering the quiz questions and check your final score!

## 🎮 How to Play

1. Read the displayed question.
2. Select one of the four answer options.
3. Click **NEXT** to continue to the next question.
4. Answer all 10 questions before or as the timer expires.
5. View your final score and review your answers.
6. Click **RESTART QUIZ** to play again.

The main objective of this project is to strengthen JavaScript fundamentals by building an interactive quiz application while practicing DOM manipulation, event handling, arrays, functions, timers, conditional statements, and dynamic HTML rendering.
